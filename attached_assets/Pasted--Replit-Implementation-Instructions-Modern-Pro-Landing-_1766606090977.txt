## 🎨 Design System Used

This landing page follows the **Modern Pro / Apple Design System**:

### Colors

- **Primary**: Blue-600 (#2563EB) for buttons and accents
- **Text**: Gray-900 (#111827) for headlines, Gray-600 (#4B5563) for body
- **Background**: Gray-50 (#F9FAFB) for page, White for cards
- **Borders**: Gray-200 (#E5E7EB) for subtle separators

### Typography

- **Font**: System font stack (matches Inter/SF Pro aesthetic)
- **Headlines**: 4xl mobile, 5xl desktop (36px → 48px)
- **Subheads**: lg (18px)
- **Body**: base (16px)
- **Letter Spacing**: -2% on headlines for premium look

### Spacing

- **Card Padding**: 8 (32px) - generous Apple-style spacing
- **Border Radius**: 2xl (16px) for cards, xl (12px) for buttons
- **Shadows**: Subtle, not heavy (shadow-sm, shadow-md)

### Component Patterns

- **Cards**: White background, gray border, subtle shadow, hover effect
- **Buttons**: Blue-600 primary, white secondary, rounded corners
- **Icons**: Colored backgrounds (blue-100, green-100, etc.)

## 🆘 Troubleshooting

**If icons don’t show:**

- Run: `npm install lucide-react`
- Verify imports at top of file are correct

**If Tailwind styles don’t work:**

- Make sure `tailwind.config.js` includes this file’s path
- Restart the Replit dev server

**If buttons don’t navigate:**

- Check your routing setup in App.tsx or main.tsx
- Verify routes match your actual page paths (e.g., `/dashboard`)

**If fonts look off:**

- The design uses system fonts (inherits from body)
- Should match Inter or SF Pro aesthetic automatically

**If colors look wrong:**

- Check that Tailwind is processing the file
- Try hard refresh (Ctrl+Shift+R)
