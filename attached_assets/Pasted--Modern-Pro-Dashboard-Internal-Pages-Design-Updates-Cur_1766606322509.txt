## 🎨 Common Design System for All Pages

### Colors

```css
/* Status Colors */
--applied: #F3F4F6 (gray)
--screening: #FED7AA (orange)
--interview: #BFDBFE (blue)
--offer: #DDD6FE (purple)
--hired: #BBF7D0 (green)

/* UI Colors */
--primary: #2563EB (blue-600)
--success: #10B981 (green-500)
--warning: #F59E0B (orange-500)
--danger: #EF4444 (red-500)
```

### Spacing

```css
/* Card padding */
padding: 24px; /* p-6 */

/* Card gaps */
gap: 16px; /* gap-4 */

/* Section spacing */
margin-bottom: 32px; /* mb-8 */
```

### Typography

```css
/* Page titles */
font-size: 30px; /* text-3xl */
font-weight: 700; /* font-bold */

/* Card titles */
font-size: 18px; /* text-lg */
font-weight: 600; /* font-semibold */

/* Body text */
font-size: 14px; /* text-sm */
color: #6B7280; /* text-gray-500 */
```
