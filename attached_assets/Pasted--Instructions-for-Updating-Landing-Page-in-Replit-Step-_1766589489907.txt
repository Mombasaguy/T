# Instructions for Updating Landing Page in Replit

## Step 1: Locate Your Current Landing Page

Your current landing page is likely at one of these locations:

- `src/pages/index.tsx` or `src/pages/Index.tsx`
- `src/components/LandingPage.tsx`
- `app/page.tsx` (if using Next.js App Router)
- `pages/index.tsx` (if using Next.js Pages Router)

## Step 2: Install Required Icons (if not already installed)

In your Replit Shell, run:

```bash
npm install lucide-react
```

## Step 3: Replace Your Current Landing Page

1. Open your main landing page file (likely `src/pages/index.tsx` or similar)
1. Delete the current content
1. Copy the entire content from `landing-page-new.tsx`
1. Paste it into your landing page file

## Step 4: Update Routing/Navigation

Make sure your main route (`/`) points to this new landing page component.

**If using React Router:**

```tsx
// In your App.tsx or main router file
import LandingPage from './pages/LandingPage';

<Route path="/" element={<LandingPage />} />
```

**If using Next.js:**
The file should already be at `pages/index.tsx` or `app/page.tsx`

## Step 5: Connect the Search Button

Update the “Search Now” button to navigate to your search page:

Find this line (around line 86 in the new code):

```tsx
<button className="mt-4 px-12 py-4 bg-gradient-to-r...">
```

Replace it with:

```tsx
<button 
  onClick={() => window.location.href = '/dashboard'} // Or your search route
  className="mt-4 px-12 py-4 bg-gradient-to-r from-blue-500 to-purple-600 text-white text-lg font-semibold rounded-xl hover:shadow-2xl hover:shadow-purple-500/50 transition-all duration-300 flex items-center gap-3 mx-auto"
>
  <Sparkles className="w-5 h-5" />
  Search Now
</button>
```

Or if using React Router:

```tsx
import { useNavigate } from 'react-router-dom';

// Inside your component:
const navigate = useNavigate();

<button 
  onClick={() => navigate('/dashboard')}
  className="..."
>
  <Sparkles className="w-5 h-5" />
  Search Now
</button>
```

## Step 6: Connect Example Search Buttons

Find the example searches section (around line 97) and make them functional:

```tsx

  </button>

```

## Troubleshooting

**If icons don’t show:**

- Make sure `lucide-react` is installed: `npm install lucide-react`
- Check that imports are correct at the top of the file

**If Tailwind styles don’t work:**

- Make sure your `tailwind.config.js` includes this file’s path
- Restart the Replit dev server

**If navigation doesn’t work:**

- Check your routing setup in `App.tsx` or `main.tsx`
- Verify the routes match your actual page paths

**If the gradient background doesn’t show:**

- Make sure Tailwind’s gradient utilities are enabled in your config
- Try refreshing the page hard (Ctrl+Shift+R)

## Need Help?

If something doesn’t work:

1. Check the browser console for errors (F12 → Console tab)
1. Verify all imports are correct
1. Make sure `lucide-react` is installed
1. Check that your routing is set up correctly
1. Try clearing cache and hard refresh (Ctrl+Shift+R)
