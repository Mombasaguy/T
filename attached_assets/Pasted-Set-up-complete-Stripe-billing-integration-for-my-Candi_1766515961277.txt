Create server/routes/stripe.js with these endpoints:

1. POST /api/stripe/create-checkout-session
   - Accepts: { priceId, userId, email, plan }
   - Creates Stripe checkout session
   - Includes 14-day trial
   - Allows promotion codes
   - Returns: { url } for redirect

2. POST /api/stripe/create-portal-session
   - Accepts: { customerId }
   - Creates billing portal session for managing subscription
   - Returns: { url }

3. POST /api/stripe/webhook
   - Handles these events:
     * checkout.session.completed → User subscribed
     * customer.subscription.updated → Subscription changed
     * customer.subscription.deleted → User cancelled
     * invoice.payment_succeeded → Payment successful
     * invoice.payment_failed → Payment failed
   - Use express.raw() middleware for webhook signature verification
   - Verify signature with stripe.webhooks.constructEvent()
   - Log all events to console for now (TODO: update database)

4. GET /api/stripe/config
   - Returns: { publishableKey } for frontend

Use these environment variables (I'll add them to Secrets):
- process.env.STRIPE_SECRET_KEY
- process.env.STRIPE_WEBHOOK_SECRET
- process.env.APP_URL (for success/cancel URLs)

Success URL: ${APP_URL}/welcome?session_id={CHECKOUT_SESSION_ID}
Cancel URL: ${APP_URL}/pricing

Add handleSubscribe function:
```javascript
const handleSubscribe = async (plan) => {
  const priceIds = {
    professional: process.env.REACT_APP_STRIPE_PRICE_PROFESSIONAL,
    team: process.env.REACT_APP_STRIPE_PRICE_TEAM
  };

  const response = await fetch('/api/stripe/create-checkout-session', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      priceId: priceIds[plan],
      userId: user?.id || 'guest',
      email: user?.email || '',
      plan: plan
    })
  });

  const { url } = await response.json();
  window.location.href = url;
};
```
